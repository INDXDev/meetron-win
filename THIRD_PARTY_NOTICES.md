## Apple Audio Server Driver Plug-in sample

`native/audio-driver/vendor/apple/MeetingCopilotAudio.c` is derived from
Apple's “Creating an Audio Server Driver Plug-in” sample, retrieved from
Apple Developer Documentation. Meetron changes the device identities,
build layout, display resources, and IO path to implement a stereo loopback.

The original source is Copyright © 2024 Apple Inc. Its license is preserved
verbatim at `native/audio-driver/vendor/apple/LICENSE.txt`.

Source documentation:

GPL-3.0-only license. The Apple sample portions remain subject to Apple's
preserved license notice.
